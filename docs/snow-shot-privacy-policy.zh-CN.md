# Snow Shot 隐私政策

更新日期：2026 年 10 月 19 日

Snow Shot 由 **Chao Huang** 运营，以 **Snow Apps** 名义发布。本政策说明应用、官方在线服务和
本网站如何处理您的信息。

如有隐私问题，或希望申请访问、更正、删除相关信息，请联系
**[chao@mgchao.top](mailto:chao@mgchao.top)**。

## 设备上的内容

截图、标注、录屏、普通文字识别和二维码识别在您的设备上运行。使用在线功能或连接 AI 客户端时，
部分内容可能会发送到其他服务，具体见下文。

Snow Shot 会处理您截取、打开或选择的图片、文件、剪贴板内容、文字和标注。启用相应功能后，
录屏还可以包含系统声音、麦克风声音、摄像头画面以及键盘、鼠标效果。

可编辑的录屏源文件可能保留鼠标位置、点击和时间信息，即使鼠标效果处于隐藏状态。
启用键盘显示效果时，源文件还会保留按键事件。

应用会在本地保存设置、截图历史、固定到屏幕的内容、录屏、缩略图和临时文件。截图历史可能包含原始屏幕图像，
其范围可能大于您最终导出的裁剪区域。固定到屏幕的历史记录可能包含图片、文字、识别结果、原文件名与路径、
窗口位置和时间信息。

您可以调整历史记录上限、保留指定内容、清除历史与缓存，以及选择存储和输出目录。
截图历史和已关闭的固定到屏幕窗口历史的默认上限为七天、100 条、1 GiB；仍打开的固定到屏幕窗口另行保存。
关闭历史记录会停止保存新记录，不会删除已有内容，也可能暂停自动清理。请使用清除历史记录的
功能移除已保存的内容。

用于剪贴板的图片通常会在应用运行时清理，默认保留七天；损坏的设置文件备份通常会在应用运行时
清理，默认保留 30 天。录屏源文件和恢复文件可能保留在录屏旁边，不受历史记录上限约束。
不再需要编辑或恢复录屏时，您可以删除这些文件。导出文件或自定义目录中的文件由您管理。

## 在线功能与您选择的服务

使用在线功能时，应用会向所选服务发送完成任务所需的内容。您启用的自动操作，例如自动翻译，
也可能发送请求。您可以在设置中更换服务，或关闭相应的自动操作。

- **表格和公式识别：**官方服务接收处理后的图片，在私有识别服务器上完成识别。
- **AI 转换和翻译：**官方服务将相关图片、文字、指令和模型选项转发给已配置的 AI 服务商。
  此项集成的服务文档使用阿里云百炼；服务商如何处理数据，取决于所用服务、区域和方案。
  详情可参阅[阿里云的隐私说明](https://help.aliyun.com/zh/model-studio/privacy-notice)。
- **自定义 AI 和翻译服务：**您配置的服务会收到提交的内容，以及调用该服务所需的凭据。
  处理地点、保留期限和模型训练规则由该服务的条款决定。
- **云上传：**导出的图片会发送到您选择的 S3 兼容存储服务。根据您的配置，上传文件可能通过
  公开链接或 CDN 链接访问。请通过对应服务管理或删除远程文件。取消上传请求不代表服务已经
  收到的文件一定会被删除。

官方 API 使用 HTTPS。自定义服务的连接方式取决于您配置的端点。发送敏感内容前，请阅读所选
服务商的条款，了解保留期限和模型训练规则；不同服务商、不同方案的规则可能不同。

下载识别模型时，应用会向模型托管服务（目前为 ModelScope）请求文件，无需因此向该服务发送您的截图。

## 官方服务的运行信息

官方 API 会在接收网络请求时获得您的 IP 地址，并使用由该地址生成的标识符来执行用量限制、
防范滥用。这是一种假名标识，并非匿名信息。服务还会记录请求时间、使用的功能和模型、
成功或失败结果，以及用量和核算信息。

服务数据库保存上述运行记录，不建立您提交的图片、提示词、翻译文本或识别结果的内容历史库。
识别工作进程在内存中处理图片。托管系统、网络日志、备份和外部 AI 服务商是独立的处理环节，
因此这不代表处理请求的所有系统都不保留数据。

运行记录会自动清理。清理规则的默认值为：操作结算后，其本身及相关记录保留 90 天，用量汇总和
符合清理条件的不活跃标识保留 400 天。这些是可配置的默认值，并非保证的最长保留期限；尚未完成的
操作，或仍被其他操作需要的记录，可能保留更久。日志、备份和外部服务商使用各自的保留设置。
如需了解官方服务的保留期限或处理地点，请联系我们。

## 凭据、诊断与连接的 AI 客户端

自定义服务密钥和云存储凭据保存在本地配置文件中。这些文件和常规设置导出不会加密，可能包含您的
凭据，请妥善保管它们及相关备份。通过 MCP 导出的设置会隐藏凭据字段。

Snow Shot 会在您的设备上保留诊断日志和崩溃报告，帮助排查问题。它们可能包含应用和会话信息、
耗时、图片尺寸、模型标识及错误。应用会尝试移除密钥及敏感路径、网址信息，但诊断归档或崩溃转储
仍可能包含敏感内容，包括应用内存中的数据。自动上传崩溃报告处于关闭状态，是否导出并分享诊断归档
由您决定。官方在线服务也会使用日志、指标和链路追踪来维护服务、调查故障。

MCP 用于让 AI 客户端与 Snow Shot 协作，默认关闭。启用后，经过认证的本地连接可以让客户端
访问受支持的截图、文件、识别内容、设置及应用操作。客户端可能将返回的内容发送给其使用的 AI 服务。
请检查该客户端的设置与隐私条款，并在不需要时关闭 MCP 或断开连接。

## 本网站与应用更新

网站使用浏览器存储记住您选择的语言和外观。可选的语言排查信息保存在浏览器会话中。
您可以通过清除此网站的浏览器数据移除这些信息。网站通过 Google Fonts 加载字体，字体服务会收到
提供文件所需的网络信息。下载、源代码和社区链接会带您前往相应的外部服务。

Microsoft Store 安装的版本通过商店更新。根据您的设置，独立安装版可以自动联系所选的发布服务
（目前为 GitHub 或 Gitee）查询并下载更新。模型托管服务、发布服务和网站托管系统会收到响应请求所需的网络信息，
也可能保留各自的访问日志。

## 您的选择与隐私请求

您可以停止使用在线功能、移除服务凭据和上传目标、关闭 MCP、清除本地历史，以及删除已保存的
文件。卸载 Microsoft Store 版本通常会移除软件包管理的数据。自定义目录中的文件、导出的
录屏或图片，以及远程上传文件，需要另外管理。

清除本地历史不会删除官方服务的运行记录或第三方上传文件。如需查询官方服务持有的信息，
或申请访问、更正、删除，请发送邮件至 **[chao@mgchao.top](mailto:chao@mgchao.top)**，
并提供有助于定位相关记录的信息。我们可能需要核实您与这些记录的关系；请勿发送无关的敏感截图
或服务密码。

Snow Shot 的信息处理方式发生变化时，我们会更新本政策。页面顶部的日期表示最近一次修订时间。
