# Pin screenshots and record your screen with Snow Shot

[All guides](README.md) · [简体中文](zh-CN/pin-and-record.md)

Pinning keeps a reference in view while you work in another application.
Recording captures a sequence of actions when one screenshot cannot explain it.
Both are available in the full edition and Mini.

## Pin a reference above other windows

1. Capture a region with **F1** and choose **Pin to screen** in the toolbar.
2. Move the pinned window beside your working area and adjust its size as needed.
3. Use the pinned window's controls or context menu to manage the reference.

To pin existing clipboard content, use **F3**. This is a different action from
starting a screenshot and pinning the selected region. You can configure either
action in the application's shortcut settings.

Use pinned references for comparing a design, reading an error message while
editing code, or keeping instructions beside a task. Review pinned-history
retention in settings if those references contain sensitive content.

## Record a short demonstration

1. Start **Screen recording** from Snow Shot's action controls or a shortcut you
   have assigned, then select the area to record.
2. Check the recording settings: enable system audio or microphone audio only
   when needed, and grant the corresponding operating-system permissions.
3. Start the recording and perform the demonstration.
4. Stop recording, complete export, and play the saved file to check the picture
   and audio before sharing it.

Recording is not assigned the screenshot's **F1** binding. Configure a dedicated
shortcut if you use it frequently. Avoid changing display scaling or moving the
target to another monitor during a demonstration.

## Choose what the recording includes

Check audio sources, camera options and keyboard/mouse presentation before
recording. A silent microphone track can result from an incorrect input device
or a missing OS permission. A short sample is a useful check before a long session.

Editable recording source files can retain cursor positions, clicks and timing;
keyboard events are retained when the keyboard overlay is enabled. Hiding an
effect does not necessarily remove its source data. Share the intended exported
video, and review the [privacy policy](https://snowshot.top/privacy.html) when
working with sensitive material.
