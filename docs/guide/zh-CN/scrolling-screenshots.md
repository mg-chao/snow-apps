# 使用 Snow Shot 截取滚动长截图

[全部指南](README.md) · [English](../scrolling-screenshots.md)

滚动截图通过连续捕获有重叠区域的画面，拼接出一张长图。
适合保存一屏放不下的网页、聊天记录或其他可滚动桌面内容。
它捕获的是应用显示的画面，不是直接导出网页底层文档。

## 截取一张长图

1. 打开目标应用，将内容停在需要截取的起始位置。
2. 按 **F1**，选中需要滚动的内容区域，尽量排除固定导航、侧栏和不会随内容滚动的部分。
3. 在截图工具栏选择**滚动截图**。也可以在设置中给滚动截图动作绑定独立全局快捷键。
4. 平稳滚动目标内容，保持相邻画面有重叠，并观察拼接预览。过程中不要移动窗口、调整页面缩放或改变显示缩放。
5. 获取所需内容后，通过滚动截图控件结束捕获，检查完整结果，再复制或保存。

滚动控件也提供自动滚动和方向选择。排查不熟悉的应用时，建议先手动滚动，确认滚动输入作用于正确区域。

## 拼接异常时如何处理

| 现象 | 检查方法 |
| --- | --- |
| 页头重复、工具栏叠在内容上 | 重新选择区域，排除固定位置的界面元素 |
| 滚动了错误的面板 | 将鼠标放到目标内容区，先尝试一小步手动滚动 |
| 丢行、重复行或错位 | 放慢滚动速度，保留足够的前后画面重叠 |
| 图片加载后页面发生位移 | 等待图片加载完成，避免动画和动态变化的内容 |
| 切换显示器后捕获停止 | 完成显示器或缩放调整后，重新选择截图区域 |

虚拟列表可能在滚动时替换已有内容，动画也可能改变相邻帧的像素。
如果持续拼接不稳定，可分成较短的片段截图，或使用目标应用自身的导出功能。
浏览器的整页导出与桌面滚动截图适用的场景不同。

分享前请检查长图的顶部、中间和底部，确认没有漏行或重复；出现预览并不代表每一行都已完整保存。
