# Snow Shot 桌面贴图与屏幕录制

[全部指南](README.md) · [English](../pin-and-record.md)

贴图可以让参考资料保持在其他窗口上方；录屏用于说明一张截图难以表达的连续操作。
完整版和 Mini 都提供这些能力。

## 将参考内容固定到屏幕

1. 按 **F1** 截取区域，在截图工具栏选择**固定到屏幕**。
2. 将贴图移动到工作区域旁边，按需要调整大小。
3. 使用贴图窗口的控件或右键菜单管理参考内容。

已有剪贴板内容可以按 **F3** 贴到屏幕。它与“先截图，再将选区贴图”是两个不同的动作，
可以分别在应用快捷键设置中配置。

贴图适合对照设计稿、边看报错边修改代码，或将操作说明放在任务旁边。
内容涉及隐私时，也请检查贴图历史的保留设置。

## 录制一段操作演示

1. 从 Snow Shot 的动作入口或已配置的快捷键启动**屏幕录制**，选择需要录制的区域。
2. 检查录制设置，仅在需要时启用系统音频或麦克风，并允许对应系统权限。
3. 开始录制，执行要演示的操作。
4. 停止录制并完成导出，播放保存的文件，检查画面和声音后再分享。

录屏并不使用截图的 **F1** 默认绑定；经常录制时可分配独立快捷键。
演示过程中尽量不要修改显示缩放或将目标窗口移到其他显示器。

## 确认录制内容

录制前检查音频来源、摄像头选项和键盘鼠标展示设置。
麦克风没有声音时，先确认输入设备和系统权限；长时间录制前可先保存一段短样例。

可编辑录制源文件可能保留光标位置、点击和时间信息；开启键盘展示时会保留键盘事件。
隐藏某个效果并不一定删除对应源数据。请分享预期的导出视频，处理敏感内容时阅读
[隐私政策](https://snowshot.top/zh/privacy.html)。
