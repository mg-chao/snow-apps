# Snow Shot 使用指南

[项目首页](../../../README.zh-CN.md) · [English](../README.md) ·
[下载](https://github.com/mg-chao/snow-apps/releases/latest)

Snow Shot 是面向 Windows 和 macOS 的免费开源截图工具，集成标注、文字识别、贴图和录屏。
这里的指南面向当前原生桌面版本。

| 我想做什么 | 对应指南 |
| --- | --- |
| 选择安装包，完成第一张截图 | [快速上手](getting-started.md) |
| 保存超出一屏的网页或聊天记录 | [滚动长截图](scrolling-screenshots.md) |
| 不使用云端 OCR，从图片提取文字 | [离线 OCR 文字识别](offline-ocr.md) |
| 将资料置顶或录制操作过程 | [桌面贴图与录屏](pin-and-record.md) |

完整版与 Mini 的识别功能不同，版本选择、CPU 架构和快捷键设置见快速上手指南。
文档中的快捷键为默认值，已有自定义设置可能不同。

## 官方入口

- 源码和问题反馈：[mg-chao/snow-apps](https://github.com/mg-chao/snow-apps)
- 安装包和更新日志：[GitHub Releases](https://github.com/mg-chao/snow-apps/releases)
- 官网和下载选择：[snowshot.top](https://snowshot.top/zh/)
- 数据处理说明：[隐私政策](https://snowshot.top/zh/privacy.html)

反馈问题时请附上版本号、完整版或 Mini、系统版本、CPU 架构和复现步骤。
截图问题还应说明显示缩放比例和被截取的应用，示例中请去掉私人内容。

源码构建请阅读 [AGENTS.md](../../../AGENTS.md) 和[平台构建文档](../../../README.md#development-and-repository-layout)。
