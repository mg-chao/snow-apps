# Snow Shot 离线 OCR：从截图提取文字

[全部指南](README.md) · [English](../offline-ocr.md)

Snow Shot 可以在本机识别截图中的文字，用于复制无法选中的报错信息、段落或其他图片内容。
安装所需模型资源后，标准 OCR 不依赖云端文字识别服务。

## 离线使用前的准备

| 安装方式 | 需要准备什么 |
| --- | --- |
| Windows 完整版离线安装包 | 已包含默认 OCR 资源；用样例确认目标语言的识别效果 |
| 完整版在线安装包 | 断网前先完成相关组件和模型下载 |
| Mini | 在设置中启用手动文字识别，并完成首次资源下载 |

较小的安装包不一定包含全部识别资源。需要在隔离网络环境安装时，请提前准备 Windows 完整版离线包，
并验证实际需要的文字识别流程。

## 从截图识别文字

1. 按 **F1**，选中包含待识别文字的区域。
2. 在截图工具栏选择**文本识别**。
3. 检查识别结果、修正错误，再复制或导出文字。
4. 经常使用时，可以为文字识别或识别后复制动作绑定独立全局快捷键；后者会复制结果并结束截图会话。

尽量只框选需要的文字，并保持字体清晰可读。过小、模糊、艺术字体和低对比度内容可能影响准确率。
复用命令、账号或表格数据前，请检查数字、标点和形近字符。

## 文字、表格、二维码和翻译有什么区别

- **文字识别**：完整版支持；Mini 需要启用并准备资源。
- **表格、二维码识别**：使用完整版，Mini 不包含这些工具。
- **翻译**：有独立的服务商和网络要求。本地 OCR 不意味着在线翻译服务可以离线使用。
- **可选 AI 功能**：处理位置和数据流向取决于所选服务商或连接的应用。

本地内容、在线功能和应用连接的数据处理方式见[隐私政策](https://snowshot.top/zh/privacy.html)。

## 常见问题

提示下载资源时，请联网完成下载后再断网测试。找不到表格或二维码识别时，先确认是否使用了 Mini。
识别错误可先尝试放大文字、缩小选区、简化背景。
仍可稳定复现的问题，请在 [GitHub Issues](https://github.com/mg-chao/snow-apps/issues)
附上版本、版本类型、识别语言和不含敏感信息的样例。
