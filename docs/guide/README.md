# Snow Shot user guides

[Project home](../../README.md) · [简体中文](zh-CN/README.md) ·
[Download](https://github.com/mg-chao/snow-apps/releases/latest)

Snow Shot is a free, open-source screenshot, annotation, OCR and screen recording
tool for Windows and macOS. These guides cover the current native desktop app.

| I want to… | Start here |
| --- | --- |
| Install the right package and take a screenshot | [Getting started](getting-started.md) |
| Capture a page longer than my screen | [Scrolling screenshots](scrolling-screenshots.md) |
| Extract text without a cloud OCR service | [Offline OCR](offline-ocr.md) |
| Keep a reference above other windows or record a demonstration | [Pinning and screen recording](pin-and-record.md) |

The full edition and Mini have different recognition features. Package selection,
architecture support and keyboard setup are explained in the getting started guide.
Shortcuts in these guides are defaults; your saved settings may differ.

## Official project links

- Source and issues: [mg-chao/snow-apps](https://github.com/mg-chao/snow-apps)
- Releases and changes: [GitHub Releases](https://github.com/mg-chao/snow-apps/releases)
- Website and download selector: [snowshot.top](https://snowshot.top/)

When reporting an issue, include the Snow Shot version, full/Mini edition, operating
system, CPU architecture, and steps to reproduce it. For capture problems, include
display scaling and the affected application. Remove private content from examples.

For building from source, use [AGENTS.md](../../AGENTS.md) and the
[platform build documents](../../README.md#development-and-repository-layout).
