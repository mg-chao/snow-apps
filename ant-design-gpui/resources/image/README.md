# Image fixtures

Original deterministic RGBA artwork, copyright 2026 mg-chao, Apache-2.0.
Regenerate with `node scripts/generate_image_assets.mjs`. Both the genuine
Ant Design browser reference and native GPUI captures consume these exact bytes.
Asymmetric shapes and transparent regions expose transform order and alpha errors.
The manifest records dimensions and SHA-256 hashes. No remote image service is
needed for the gallery or verification.
